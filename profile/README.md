# BLB3D Printing

Bambu Lab print farm in Huntington, Indiana, and the software built to run it.

- **FilaOps** — open-source ERP for 3D print farms.
- **Aeonyx** — agent governance and enforcement for AI-assisted development.
- **FilaOps Relay** — distribution, licensing, and updates for FilaOps.

This repository also carries the organization's reusable CI workflow (`.github/workflows/ci.yml`)
and the starter template each repo uses to call it (`workflow-templates/ci.yml`).
